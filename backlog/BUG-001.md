# Bug: Windows asyncio ProactorEventLoop crash on uvicorn CLI

**ID:** `BUG-001`
**Status:** `Todo`
**Gitflow Branch:** `bugfix/BUG-001-asyncio-uvicorn-windows`
**Dependencies:** `None`

---

## Context
When running the FastAPI server via the CLI (`python -m uvicorn src.main:app`) on Windows, testing the `/api/v1/tickets/process` endpoint results in a 500 Internal Server Error. 

This occurs because `psycopg` (used by LangGraph's Postgres checkpointer) requires a `SelectorEventLoop` on Windows to run asynchronously. Although `src/main.py` explicitly sets the `WindowsSelectorEventLoopPolicy`, invoking the server directly via `uvicorn` creates the event loop *before* `main.py` runs, resulting in the default `ProactorEventLoop` being used anyway.

### Steps to Reproduce
1. Start the server on Windows: `python -m uvicorn src.main:app`
2. Open Swagger UI at `http://localhost:8000/docs`.
3. Hit `POST /api/v1/tickets/process` with a valid JSON payload.

### Expected Behavior
The LangGraph agent processes the request and returns a 200 OK with the agent's message.

### Actual Behavior
The server crashes with a 500 error: 
`"detail": "Error executing agent workflow: Psycopg cannot use the 'ProactorEventLoop' to run in async mode. Please use a compatible event loop..."`
