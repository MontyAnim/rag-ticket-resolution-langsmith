# Bug: token_usage evaluator fails due to missing prompt_tokens attribute

**ID:** `BUG-002`
**Status:** `Done`
**Gitflow Branch:** `bugfix/BUG-002-token-usage-runtree`
**Dependencies:** `None`

---

## Context
During QA of the LangSmith `run_evals.py` CI/CD pipeline, the `token_usage` evaluator was observed failing across all runs. It attempts to access `.prompt_tokens` on the LangSmith `RunTree` object, which is no longer valid or present in the current SDK version.

Affected components:
- `src/evals/llm_judge.py` (or wherever `token_usage` evaluator is implemented).

### Steps to Reproduce
1. Execute `python -m src.scripts.run_evals`
2. Open LangSmith UI and navigate to the latest evaluation run.
3. Observe that `token_usage` scores are empty/failed and the error trace shows `AttributeError("'RunTree' object has no attribute 'prompt_tokens'")`.

### Expected Behavior
The evaluator should successfully extract the token usage from the RunTree or the LLM output metadata and return a numerical score representing total tokens.

### Actual Behavior
The evaluator crashes with `AttributeError("'RunTree' object has no attribute 'prompt_tokens'")`.
